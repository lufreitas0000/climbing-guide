\section{Introdução}
O \texttt{climbingguide} é um motor híbrido (TeX/Lua) desenhado para separar completamente a lógica matemática e topológica da camada de apresentação visual.

\section{Macros de Front Matter}
Utilize \texttt{\textbackslash CGSplitBackground\{0.5\}\{bg\_beige\}\{brand\_color\}} para criar fundos divididos para índices e notas de atenção.
Utilize \texttt{\textbackslash CGSidebarTitle\{Título\}} para cabeçalhos com o bloco de destaque.
