\section{System Architecture}

The system is strictly partitioned into decoupled, orthogonal layers adhering to SOLID principles:

\begin{itemize}
    \item \textbf{\texttt{src/}}: Core presentation macros (\LaTeX) and business logic (pure Lua modules).
    \item \textbf{\texttt{tests/}}: Isolated TDD test suites verifying Lua mathematics, font resolution, and visual geometry without compiling production targets.
    \item \textbf{\texttt{scripts/}}: POSIX CI/CD automation tools for font cache auditing, log filtering, and fixed-delimiter schema validation.
    \item \textbf{\texttt{doc/}}: Technical architecture logs, continuous integration specs, and rendered engine manuals.
\end{itemize}

\section{Typography}

Binary fonts are mapped using \texttt{fontspec} without system-level coupling:

\begin{itemize}
    \item \textbf{\texttt{\textbackslash CGTitleFont}}: Barlow Condensed (Titles, route names, indices).
    \item \textbf{\texttt{\textbackslash CGCoverFont}}: Bebas Neue (Full-bleed cover and zone headers).
    \item \textbf{\texttt{\textbackslash CGBaseFont}}: Default Sans-Serif / Latin Modern Sans (Body and tabular text).
    \item \textbf{\texttt{\textbackslash CGItalicFont}}: Default Sans-Serif Slanted (Grades, gear, route setters).
\end{itemize}

\section{Data Pipeline and Export Hook}

During document compilation, the \LaTeX\ engine records route data into Lua memory. At document termination (\texttt{\textbackslash AtEndDocument}), the pipeline executes:

\begin{enumerate}
    \item \textbf{Lexical Sanitization}: Strips TeX commands (\texttt{\textbackslash textbf}, \texttt{\textbackslash color}, \texttt{\textbackslash newline}, \texttt{\~{}}) via \texttt{sanitize\_tex.lua}, storing pure UTF-8 strings.
    \item \textbf{Pure Sorting}: Applies Strict Weak Ordering via \texttt{route\_sorter.lua} (Grade $\rightarrow$ Sector $\rightarrow$ Name $\rightarrow$ ID).
    \item \textbf{JSON Export}: Encodes data into \texttt{export/database.json} with Unicode control characters (\texttt{U+0000} to \texttt{U+001F}) escaped per RFC 8259 via \texttt{export\_json.lua}.
    \item \textbf{Plain Text Export}: Encodes sorted data into \texttt{export/list\_alpha.txt} and \texttt{export/list\_grade.txt} using the strict schema:
    \begin{quote}
    \texttt{[ID] | [Name] | [Grade] | [Length] | [Gear] | [Setter] | [Sector] | [Zone]}
    \end{quote}
\end{enumerate}
