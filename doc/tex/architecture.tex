\section{System Architecture}

The engine enforces an absolute decoupling between the presentation layer (\LaTeX) and the data/logic layer (Lua). Production source files remain purely declarative databases with zero manual spacing, hardcoded breaks, or visual overrides.

\subsection{Core Design Principles}
\begin{itemize}
    \item \textbf{Single Responsibility Principle (SRP)}: Presentation macros, state tracking, font loading, geometry boundaries, TikZ overlays, sorting algorithms, lexical sanitization, and serialization are isolated into dedicated modules.
    \item \textbf{State vs. Presentation Decoupling}: \texttt{cg-api.sty} manages dataflow and backend counters; \texttt{cg-macros.sty} handles visual output and page layout.
    \item \textbf{Immutability \& Pure Functions}: Algorithmic operations never mutate global state; they clone inputs and return new structures.
    \item \textbf{Zero TeX Leakage}: TeX control sequences embedded in route parameters are sanitized before entering in-memory state.
\end{itemize}
