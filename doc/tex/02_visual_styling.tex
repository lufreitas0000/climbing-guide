\subsection{Typography \& Font Loading}
Fonts are configured in \texttt{cg-fonts.sty} via \texttt{fontspec}:
\begin{itemize}
    \item \textbf{\texttt{\textbackslash CGTitleFont}}: Barlow Condensed (Titles, sector banners, route numbers, indices).
    \item \textbf{\texttt{\textbackslash CGCoverFont}}: Bebas Neue (Full-bleed cover titles, zone banners).
    \item \textbf{\texttt{\textbackslash CGBaseFont}}: Sans-Serif Regular / Latin Modern Sans (Body copy, notes).
    \item \textbf{\texttt{\textbackslash CGItalicFont}}: Sans-Serif Slanted / Oblique (Grades, lengths, gear notes).
\end{itemize}
