\section{Data Pipeline \& CI/CD Scripts}

The engine implements a continuous data extraction pipeline during \LaTeX\ compilation, safeguarded by a suite of POSIX Bash scripts executed sequentially by the \texttt{Makefile}.

\subsection{Compilation Lifecycle Flow}
\begin{sloppypar}
\begin{enumerate}
    \item \textbf{AST Capture}: \texttt{\textbackslash CGZoneHeader} and \texttt{\textbackslash CGSectorHeader} update topological state in Lua runtime memory.
    \item \textbf{Lexical Sanitization}: \texttt{\textbackslash CGRoute} passes raw arguments through \texttt{sanitize\_tex.lua} to store pure UTF-8 strings in \texttt{M.routes}.
    \item \textbf{Two-Pass Sector Summaries}: At sector transitions, \texttt{\textbackslash guide\_save\_sector\_summary:} writes sector tally definitions to the \texttt{.aux} file.
    \item \textbf{Document Termination Hook}: At \texttt{\textbackslash AtEndDocument}, \texttt{cg-api.sty} triggers automatic disk serialization (\texttt{database.json} and text lists).
\end{enumerate}
\end{sloppypar}

\subsection{Pipeline Scripts \& Logic}
To ensure code purity, mathematical safety, and layout stability, four primary shell scripts operate automatically as build prerequisites:

\begin{itemize}
    \item \textbf{\texttt{clean\_nbsp.sh}}: Executes a cross-platform Perl substitution across the codebase prior to compilation. It forcibly strips all invisible \texttt{U+00A0} (non-breaking space) UTF-8 characters (\texttt{\textbackslash xC2\textbackslash xA0}) injected by OS clipboards, converting them to standard ASCII spaces to prevent fatal \LaTeX\ column overflow bugs.
    \item \textbf{\texttt{check\_fonts.sh}}: Reads the \texttt{fonts.in} manifest and executes \texttt{luaotfload-tool} to audit the OS environment. Aborts the build if required proprietary fonts are missing.
    \item \textbf{\texttt{parse\_logs.sh}}: A compilation wrapper that parses the \texttt{.log} output stream. It captures critical engine failures and echoes the exact context, while gracefully silencing acceptable \texttt{Overfull \textbackslash hbox} visual warnings.
    \item \textbf{\texttt{validate\_exports.sh}}: Guarantees the schema integrity of plain text exports by iterating through every line and physically counting the pipe (\texttt{|}) delimiters to strictly validate the expected 7-pipe structure.
\end{itemize}
