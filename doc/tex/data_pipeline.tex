\section{Data Pipeline \& CI/CD Scripts}

The engine implements a continuous data extraction pipeline during \LaTeX\ compilation, safeguarded by a suite of POSIX Bash scripts executed sequentially by the \texttt{Makefile}.

\subsection{Compilation Lifecycle Flow}
\begin{sloppypar}
\begin{enumerate}
    \item \textbf{AST Capture}: \texttt{\textbackslash CGZoneHeader} and \texttt{\textbackslash CGSectorHeader} update topological state in Lua runtime memory.
    \item \textbf{Lexical Sanitization}: \texttt{\textbackslash CGRoute} passes raw arguments through \texttt{sanitize\_tex.lua} to store pure UTF-8 strings in \texttt{M.routes}.
    \item \textbf{Two-Pass Sector Summaries}: At sector transitions, \texttt{\textbackslash guide\_save\_sector\_summary:} writes sector tally definitions to the \texttt{.aux} file.
    \item \textbf{Document Termination Hook}: At \texttt{\textbackslash AtEndDocument}, \texttt{cg-api.sty} triggers automatic disk serialization (\texttt{database.json} and text lists).
\end{enumerate}
\end{sloppypar}

\subsection{Pipeline Scripts \& Logic}
To ensure code purity, mathematical safety, and layout stability, four primary shell scripts operate automatically as build prerequisites:

\begin{itemize}
    \item \textbf{\texttt{clean\_nbsp.sh}}: Executes a cross-platform Perl substitution across the entire \texttt{src} and \texttt{production} codebase prior to compilation. It forcibly locates and strips all invisible \texttt{U+00A0} (non-breaking space) UTF-8 characters (\texttt{\textbackslash xC2\textbackslash xA0}), converting them to standard ASCII spaces. This prevents fatal \LaTeX\ column overflow bugs caused by OS clipboard injection.
    \item \textbf{\texttt{check\_fonts.sh}}: Reads the \texttt{fonts.in} manifest and executes \texttt{luaotfload-tool} to audit the OS environment. If a required proprietary font (e.g., \textit{Barlow Condensed}) is missing, it aborts the build before \TeX\ initializes, preventing cascading rendering errors.
    \item \textbf{\texttt{parse\_logs.sh}}: A compilation wrapper that parses the \texttt{.log} output stream. It captures critical engine failures (e.g., \texttt{! LaTeX Error}) and echoes the exact context line to the terminal. Concurrently, it silences and gracefully accepts \texttt{Overfull \textbackslash hbox} warnings, allowing minor intentional visual overflows to compile.
    \item \textbf{\texttt{validate\_exports.sh}}: Guarantees the schema integrity of the plain text exports (\texttt{list\_alpha.txt} and \texttt{list\_grade.txt}). It iterates through every exported line, physically counting the pipe (\texttt{|}) delimiters to strictly validate the expected 7-pipe structure. If parsing fails, it fails the CI pipeline.
\end{itemize}
