\subsection{Typography Abstraction \& Semantic Hierarchy}
Typography is strictly abstracted in \texttt{cg-fonts.sty}. Direct calls to font sizing primitives (\texttt{\textbackslash LARGE}, \texttt{\textbackslash small}) in layout files are strictly forbidden; all elements map to semantic commands with explicit pt sizing:
\begin{itemize}
    \item \textbf{Base Font Loaders}: \texttt{\textbackslash CGTitleFont} (Barlow Condensed), \texttt{\textbackslash CGCoverFont} (Bebas Neue), \texttt{\textbackslash CGBaseFont} (Sans-Serif Regular), \texttt{\textbackslash CGItalicFont} (Sans-Serif Slanted).
    \item \textbf{Semantic Header Aliases}: \texttt{\textbackslash CGHeaderFont} ($9\text{pt}/11\text{pt}$), \texttt{\textbackslash CGZoneTitleFont} ($26\text{pt}/28\text{pt}$), \texttt{\textbackslash CGSectorTitleFont} ($24\text{pt}/28\text{pt}$).
    \item \textbf{Semantic Route Aliases}: \texttt{\textbackslash CGRouteNameFont} ($12\text{pt}/14\text{pt}$ bold), \texttt{\textbackslash CGGradeFont} ($10\text{pt}/12\text{pt}$ italic), \texttt{\textbackslash CGSetterFont} ($9\text{pt}/11\text{pt}$ italic), \texttt{\textbackslash CGObservationFont} ($9\text{pt}/11\text{pt}$ italic).
    \item \textbf{Semantic List Aliases}: \texttt{\textbackslash CGListRouteNameFont}, \texttt{\textbackslash CGListSectorFont}, \texttt{\textbackslash CGListGradeFont}.
\end{itemize}
