\section{Lua Backend Engine}

The Lua backend manages the in-memory route database, mathematical evaluation of climbing grades, sorting algorithms, and I/O serialization.

\subsection{Core Modules \& Function Specifications}

\begin{itemize}
    \item \textbf{\texttt{route\_sorter.lua}}
    \begin{itemize}
        \item \texttt{Sorter.sort\_by\_alpha(routes: table) $\rightarrow$ table (pure)}
        \begin{itemize}
            \item \textbf{Description}: Performs a shallow clone of the input routes table and returns a new table ordered lexicographically by Name $\rightarrow$ Sector $\rightarrow$ ID. Does not mutate original state.
        \end{itemize}
        \item \texttt{Sorter.sort\_by\_grade(routes: table, grade\_eval\_func: function) $\rightarrow$ table (pure)}
        \begin{itemize}
            \item \textbf{Description}: Returns a new sorted table ordered by numerical grade evaluation $\rightarrow$ Sector $\rightarrow$ Name $\rightarrow$ ID, satisfying Strict Weak Ordering.
        \end{itemize}
    \end{itemize}

    \item \textbf{\texttt{sanitize\_tex.lua}}
    \begin{itemize}
        \item \texttt{Sanitizer.strip\_tex\_macros(str: string) $\rightarrow$ string (pure)}
        \begin{itemize}
            \item \textbf{Description}: Scans string bytes for bracket depth. Throws a fatal error if nested braces (\texttt{depth > 1}) are detected. Strips TeX color macros, extracts payloads from formatting macros (\texttt{\textbackslash textbf}, \texttt{\textbackslash textit}, \texttt{\textbackslash emph}), and translates spacing tokens (\texttt{\textbackslash \textbackslash}, \texttt{\textbackslash newline}, \texttt{\~{}}) into standard spaces.
        \end{itemize}
    \end{itemize}

    \item \textbf{\texttt{export\_json.lua}}
    \begin{itemize}
        \item \texttt{Serializer.escape\_string(str: string) $\rightarrow$ string (pure)}
        \begin{itemize}
            \item \textbf{Description}: Escapes structural JSON delimiters and universally hex-escapes all ASCII control characters in the range \texttt{U+0000} to \texttt{U+001F} into \texttt{\textbackslash u00XX} format to guarantee RFC 8259 compliance.
        \end{itemize}
        \item \texttt{Serializer.export(filepath: string, routes: table) $\rightarrow$ boolean (impure I/O)}
        \begin{itemize}
            \item \textbf{Description}: Opens file handle at \texttt{filepath} and writes the serialized JSON array representing the route database.
        \end{itemize}
    \end{itemize}

    \item \textbf{\texttt{export\_txt.lua}}
    \begin{itemize}
        \item \texttt{TXT.export(output\_dir: string, routes: table, grade\_eval\_func: function) $\rightarrow$ boolean (impure I/O)}
        \begin{itemize}
            \item \textbf{Description}: Generates \texttt{list\_alpha.txt} and \texttt{list\_grade.txt}. Injects \texttt{N/A} placeholders for any empty or nil optional parameters to preserve strict fixed-width schema partitioning.
        \end{itemize}
    \end{itemize}
\end{itemize}
